# SOFTCROSS TECH - Landing Page & Portfolio

Official website for **SOFTCROSS TECH** ([softcrosstech.com](https://softcrosstech.com)), showcasing engineering solutions in **Industrial Automation**, **Software Development**, and **Embedded Systems / IoT**.

---

## 🚀 Featured Services

* **Industrial Automation:** Integration of weighing indicators, load cells, sensors, and communication via industrial protocols.
* **Software Development:** Control systems, real-time dashboards, scalable web applications, and custom APIs tailored to optimize each process.
* **Embedded Systems / IoT:** Design and programming of microcontrollers for data acquisition and cost-effective customized automation.
